# Command: Fix Bug

## Purpose

Initiate a full defect lifecycle run using `workflows/fix-bug.md`.

## Required Inputs

- Bug summary and observed symptom.
- Reproduction steps or evidence.
- Impact and urgency.

## Assigned Agents

- Primary: `omn-dev-1-bug-analyst`.
- Secondary: `omn-dev-1-implement`, `omn-dev-2-reviewer`, `omn-qa`.

## Outputs

- Root-cause analysis record.
- Implemented fix with regression tests.
- Updated known-issues status.
