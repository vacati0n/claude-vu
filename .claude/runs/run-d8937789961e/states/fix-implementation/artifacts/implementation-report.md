## Implementation Summary

- Change intent: the investigation-report mutation of the validator coverage verifier is derived from the instance under test, so check V4 applies it to any conforming report whatever option it recommends and however many options it evaluates, and always substitutes an option identifier the report never uses; with the unchanged run evidence the verifier now reports 6/6 COVERED with the committed investigation report caught by I1, and the mutation lookup and the V4 verdict are importable functions a test can drive.
- Approach taken: in runtime/verify_validators.py a new derivation `recommend_an_unevaluated_option` (rung 2 of the necessity and reuse ladder: it follows the six existing derivation functions and the table's existing callable-row rule) finds the `- Recommended option:` bullet, replaces the first three-digit option id on it with the lowest `O-nnn` absent from the whole text, and returns None when the bullet, an id on it, or a free id is missing; the investigation-report row of MUTATIONS points at it with check I1 and its description unchanged; the inline mutation resolution and V4 verdict of main() moved into `resolve_mutation` and `mutation_verdict` (rung 7: the analysis requires them importable, and no existing function exposes them), which main() calls with the same finding strings and the same checks-failed record; committed_instances and conforming_instance are untouched. One new test file (rung 7: no test of the verifier existed). The bundled payload mirror was regenerated by its sync command. No dependency was added.
- Design reference: root-cause analysis Fix Strategy (derive the investigation-report row from the instance, lowest unused option id, None on a missing field or no free id, keep I1 and the description, derive only with no selector fallback, extract the mutation lookup and V4 verdict from main() unchanged in behaviour, no validator, template, fixture, or run evidence change) and its Validation Plan (reproduction, new test file with the listed cases, full suite).
- Out of scope: the six other literal rows, which the analysis found pinned by their contracts; the selector functions committed_instances and conforming_instance, left as designed; every validator, template, fixture, and committed run artifact; the two count rows substituting 99, carried by the analysis as a residual for omn-tech-lead; running the release verification FR-02 in the main checkout or a hosted CI run, which the analysis routes to omn-qa after the fix.
