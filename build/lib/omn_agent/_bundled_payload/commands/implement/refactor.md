# Command: Refactor

## Purpose

Run a behavior-preserving structural improvement cycle using `workflows/refactor.md`.

## Required Inputs

- Refactor target area and motivation.
- Invariants that must not change.
- Risk tolerance and timeline.

## Assigned Agents

- Primary: `omn-tech-lead`.
- Secondary: `omn-dev-1-implement`, `omn-dev-2-reviewer`, `omn-qa`.

## Outputs

- Refactor plan with safety checks.
- Code changes with regression evidence.
- Debt reduction summary.
